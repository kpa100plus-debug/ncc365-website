# NCC 전국 센터코드 표준 (2026-08-30)

- 참조코드: `REF-NCC-CENTER-CODE-NATIONAL-20260830-01`
- 적용 기준일: 2026-08-30

## 1. 기준 원칙

- 행정안전부 행정표준코드관리시스템의 현행 10자리 행정기관·행정동 코드를 원천 식별자로 사용한다.
- 영문 지역 약어나 임의 순번을 새 센터코드로 만들지 않는다.
- 모든 시·도, 시·군·구, 읍·면·동 코드는 센터 개설 전에도 `reserved` 상태로 예약한다.
- 리(里)는 별도 센터 단위로 만들지 않고 상위 읍·면 센터에 포함한다.
- 행정구역 변경 시 기존 코드를 삭제하거나 재사용하지 않는다. `inactive` 처리하고 `successorCode`로 새 코드를 연결한다.
- 기존 `SEOUL-GANGNAM-SAMSEONG` 같은 코드는 `legacyCenterCode`에만 보존한다.
- 알 수 없는 지역을 `잘모름`으로 저장하지 않는다. 미지정은 `null`로 저장하고 관리자 확인 대상으로 분리한다.

## 2. NCC 센터코드 형식

| 단계 | 형식 | 예시 |
|---|---|---|
| 본사 | `NCC-HQ-0000000000` | 전국소비자클럽 본사 |
| 시·도/광역 | `NCC-P-{공식 10자리 코드}` | `NCC-P-1100000000` 서울특별시센터 |
| 시·군·구 | `NCC-M-{공식 10자리 코드}` | `NCC-M-1168000000` 서울특별시 강남구센터 |
| 읍·면·동 | `NCC-L-{공식 10자리 코드}` | `NCC-L-1168010100` 서울특별시 강남구 역삼동센터 |

`P`는 Province, `M`은 Municipality, `L`은 Local을 뜻한다. 공식 코드는 앞자리 0을 포함한 10자리를 그대로 보존한다.

```json
{

  "level": "local",
  "provinceName": "서울특별시",
  "municipalityName": "강남구",
  "localName": "역삼동",
  "centerName": "서울특별시 강남구 역삼동 소비자센터",
  "status": "reserved",
  "effectiveFrom": "2026-08-30",
  "effectiveTo": null,
  "successorCode": null,
  "legacyCenterCode": null
}
```

## 4. 운영 적용 규칙

1. 회원관리에서는 시·도 → 시·군·구 → 읍·면·동을 선택하며 센터명과 코드를 자동 입력한다.
2. 센터코드는 직접 타이핑하지 않고 공식 지역목록에서 선택한다.
3. 센터장·센터 팀원 지정에는 `active` 센터코드만 사용한다.
4. 명함 제작기는 회원번호 조회 시 회원의 활성 센터코드를 자동 반영한다.
5. 센터코드가 없는 회원은 명함을 생성하지 않고 관리자에게 소속센터 지정 안내를 표시한다.
6. 행정구역 개편 자료는 매월 동기화하고 변경 이력을 남긴다.
7. 같은 공식 행정코드에는 NCC 센터코드가 항상 하나만 존재해야 한다.

## 5. 2026년 자료 적용 주의

2026년 행정구역 개편으로 지역 명칭과 코드가 달라진 사례가 있으므로 과거 17개 시·도 고정 목록이나 임의 영문 슬러그를 기준 데이터로 사용하지 않는다. 운영 데이터에는 적용 기준일과 원본 행정코드를 함께 저장한다.
